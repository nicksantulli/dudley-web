What Is a Phased Release on the App Store?

Dudley Development · September 19, 2026

A phased release means an iPhone app update rolls out gradually to automatic updates over seven days. Here is what users and small app studios should know.

App UpdatesApp StorePhased ReleaseiPhone AppsIndie AppsTable Talk

A phased release on the App Store means an app update rolls out gradually instead of reaching every automatic-update user at once. Apple describes it as a seven-day staged release for version updates: 1% of eligible automatic-update users on day 1, then 2%, 5%, 10%, 20%, 50%, and 100% by day 7.

That does not mean the update is hidden from everyone else. Apple says anyone can still manually download the app or app update from the App Store during a phased release.

Sources: Apple App Store Connect Help: Release a version update in phases, Apple Support: update apps from the App Store on iPhone, Apple App Store Connect Analytics metric definitions, Apple App Store Connect Analytics dashboard overview, and the current Table Talk: Conversation Cards App Store listing.

The Short Answer

A phased release is a safety valve for app updates. Instead of sending a new version to every automatic-update user immediately, the App Store gradually expands the automatic rollout over a week.

For users, the practical meaning is simple:

  • Your phone may not auto-update the app on the first day.
  • You can usually go to the App Store and update manually if you want the new version now.
  • If the developer sees a serious issue, they can pause the rollout while they investigate.
  • Once the phased release completes, automatic-update users are eligible for the latest version supported by their device.

Apple Support also says apps downloaded from the App Store are automatically updated by default, but users can manually update apps from their App Store account screen.

The Seven-Day Schedule

Apple’s phased-release schedule for automatic updates is:

Apple says the sample is random among users with automatic updates turned on for eligible devices, and users are not notified that they are part of the phased release.

That detail matters. A phased release is not a beta, a waitlist, or a public announcement. It is a controlled distribution setting for an approved App Store version update.

Why Developers Use Phased Release

Good app updates still carry risk. A new version can pass review and testing, then run into a device-specific crash, a migration issue, a server behavior the test environment missed, or an unexpected support pattern.

Phased release gives a developer time to watch signals before every automatic-update user receives the version. Useful signals include:

  • crash reports;
  • App Store reviews and support messages;
  • analytics for opens, sessions, and key flows;
  • purchase or ad behavior if the app has monetization;
  • whether the update is reaching the intended version mix.

For a small studio, this is especially useful because one bad update can consume the whole support queue. A gradual rollout gives the team a chance to catch problems while the affected group is still smaller.

What Users Should Know

If an app update is in phased release, you may see a friend already using the new version while your phone has not auto-updated yet. That can be normal.

You can check manually:

  1. Open the App Store app on iPhone.
  2. Tap your account picture.
  3. Look for App Updates.
  4. Tap Update next to the app, or Update All.

If the update is available for your device and storefront, manual update is the fastest path. If you do nothing, automatic updates should catch up as the phased release expands.

What Phased Release Does Not Prove

A completed phased release proves distribution reached the end of Apple’s automatic-update schedule. It does not prove the update was successful as a product.

Developers still need separate evidence for:

  • first-time downloads;
  • redownloads and updates;
  • sessions and active devices;
  • crashes and support load;
  • revenue, refunds, or ad yield;
  • whether users actually used the feature that changed.

Apple’s Analytics docs make this distinction clear. First Time Downloads are a downloads metric, while sessions, active devices, crashes, and deletions are usage metrics. Apple also says some analytics only display when data is available, and usage data depends on users who have agreed to share analytics.

The practical rule is: do not confuse “rolled out” with “worked.” Rollout is distribution. Outcome is measurement.

Where Table Talk Fits

Table Talk: Conversation Cards is a live iPhone app from Dudley Development. The current U.S. App Store lookup identifies it as an Entertainment app, bundle com.nsantulli.tabletalk, version 1.1.6, requiring iOS 16.6 or later, with the current version release date listed as September 16, 2026.

Table Talk is a good example of the kind of app where phased release is useful. It is a small, offline-first social app: 420 conversation cards, an 80-card Would You Rather deck, no account, and prompts bundled inside the app. When a version update changes privacy behavior, analytics, ads, sharing, or session flow, the responsible move is to separate rollout from measurement.

That means a studio should say what it knows and what it does not. “The update is available” is different from “the update improved retention.” “No support tickets seen” is different from “no one had a problem.” “Analytics unavailable” is not the same as zero users.

FAQ

What is a phased release on the App Store?

A phased release is a staged rollout for an app version update. Apple says the update is gradually released over seven days to a random sample of users who have automatic updates turned on for eligible devices.

Can I manually update during a phased release?

Yes. Apple says apps and app updates in phased release can still be manually downloaded from the App Store by anyone at any time.

Why would an app developer use phased release?

A phased release gives the developer time to watch crash reports, support messages, analytics, and reviews before every automatic-update user receives the new version.

Does phased release affect new downloads?

Phased release is about automatic updates for an existing app version update. If you download the app manually from the App Store, you can get the current available version.
